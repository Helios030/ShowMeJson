# JSON 格式化显示（Chrome 插件）

## 安装（开发者模式）

1. 打开 Chrome → `chrome://extensions/`
2. 右上角开启「开发者模式」
3. 点击「加载已解压的扩展程序」
4. 选择本目录：`json_formatter_extension/`

## 使用

### 1) 自动美化整页 JSON

- 直接访问返回 JSON 的 URL（`Content-Type: application/json` 或页面几乎只有 JSON 文本）
- 插件会自动在当前标签页切换到美化查看页

### 2) 选中文本右键格式化

- 在任意网页中选中一段 JSON 文本
- 右键 →「格式化 JSON」
- 会打开一个新的美化查看页展示该段 JSON

## 查看页功能

- 树形可折叠展示、Key 排序
- 文本模式：原始/格式化切换 + 语法高亮（大文本会自动降级为纯文本以保证性能）
- 搜索/定位：输入关键字回车，右侧显示命中列表，可上一个/下一个跳转
- 路径复制：点击树节点后可复制对应路径（类似 JSONPath）
- 大 JSON：树形懒渲染、数组分段加载、搜索分片执行（避免卡死）

## 已知限制

- 右键格式化只针对“选中的文本”（不会自动从页面 DOM 提取非选中内容）
- 某些网站会把 JSON 包在复杂 HTML 中，自动识别可能不会触发（可用选中右键方式）
